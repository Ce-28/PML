# PML
สรุปโปรเจกต์แบบละเอียด: เปรียบเทียบโมเดล ANN vs SVM ทำนายจำนวนประตูนักเตะพรีเมียร์ลีก
ภาพรวมโปรเจกต์

โปรเจกต์นี้มีเป้าหมายเพื่อสร้างโมเดล Machine Learning ที่ทำนาย จำนวนประตู (Goals) ที่นักเตะพรีเมียร์ลีกแต่ละคนจะทำได้ โดยใช้ข้อมูลสถิติการเล่นของนักเตะ 571 คน จากไฟล์ dataset - 2020-09-24.csv แล้วเปรียบเทียบว่าระหว่างโมเดล 2 แบบ — Artificial Neural Network (ANN) และ Support Vector Machine (SVM) — แบบไหนทำนายได้แม่นยำกว่า

โปรเจกต์แบ่งออกเป็น 4 ไฟล์ที่ทำงานต่อเนื่องกัน:

Separatedata.ipynb → เตรียมข้อมูล + สำรวจข้อมูลเชิงลึก
TranANN.ipynb → เทรนและประเมินโมเดล ANN
TranSVM.ipynb → เทรนและประเมินโมเดล SVM
compare.ipynb → รวมทั้งสองโมเดลมาเปรียบเทียบกันบนชุดทดสอบเดียวกัน
1️⃣ Separatedata.ipynb — การเตรียมและสำรวจข้อมูล

ตรวจสอบแถวซ้ำ → ไม่พบข้อมูลซ้ำเลย (0 แถว) แสดงว่าข้อมูลต้นทางมีคุณภาพดีในแง่นี้
แปลงคอลัมน์ประเภทเปอร์เซ็นต์ (Tackle success %, Shooting accuracy %, Cross accuracy %) จากข้อความ "78%" ให้เป็นตัวเลขทศนิยม (0.78)

2️⃣ TranANN.ipynb — โมเดล Artificial Neural Network
สถาปัตยกรรมโมเดล

ใช้ MLPRegressor จาก scikit-learn แบบ Feed-forward Neural Network:

Hidden layers: 2 ชั้น ขนาด 64 และ 32 neurons
Activation function: ReLU
Optimizer: Adam
Learning rate: 0.001, Alpha (L2 regularization): 0.001
Early stopping: เปิดใช้งาน (validation fraction 15%, หยุดถ้าไม่ดีขึ้นใน 40 รอบ)
Max iterations: 1,500 รอบ (แต่เทรนจริงหยุดที่ 92 รอบ เพราะ early stopping ทำงาน)
ขั้นตอนเตรียมข้อมูลก่อนเข้าโมเดล
ตัดคอลัมน์ที่ทำให้เกิด Target Leakage ออก (Goals, Goals per match, Headed goals, Goals with right/left foot, Own goals) — เพราะคอลัมน์เหล่านี้คำนวณมาจากค่า Goals โดยตรง ถ้าไม่ตัดออกโมเดลจะ "โกง" คำตอบ
แบ่งข้อมูล Train/Test แบบ 80/20 (Train 456 / Test 115) โดยใช้ random_state=42 เพื่อให้ผลทำซ้ำได้
ตัวแปรตัวเลข → เติมค่าว่างด้วย median แล้ว scale ด้วย StandardScaler (สำคัญมากสำหรับ ANN เพราะ Neural Network ไวต่อสเกลของข้อมูล)
ตัวแปรหมวดหมู่ (Club, Position, Nationality) → เติมค่าว่างด้วยค่าที่พบบ่อยสุด แล้วแปลงเป็น One-Hot Encoding
ผลการประเมิน
ตัวชี้วัด	ค่า	ความหมาย
MAE	1.8126	ทำนายคลาดเคลื่อนเฉลี่ย ±1.81 ประตู
RMSE	4.1524	ค่าคลาดเคลื่อนแบบถ่วงน้ำหนักกรณีผิดพลาดมาก (penalize outlier)
R²	0.8842	โมเดลอธิบายความแปรปรวนของข้อมูลได้ 88.42%
ตัวอย่างการทำนาย (จุดเด่น-จุดด้อย)
กรณีนักเตะที่ยิง 0 ประตู → โมเดลทำนายแม่นเป๊ะ 0.00 หลายเคส
กรณี Chelsea Midfielder ยิงจริง 25 → ทำนาย 29.97 (คลาดเคลื่อน +4.97)
กรณี Arsenal Forward ยิงจริง 37 ประตู → โมเดลทำนายสูงถึง 66.46 (คลาดเคลื่อนมากถึง +29.46) ซึ่งนี่คือจุดอ่อนสำคัญ: โมเดลมีแนวโน้ม ทำนายเกินจริงอย่างมาก สำหรับนักเตะดาวยิงระดับท็อป (น่าจะเป็น Pierre-Emerick Aubameyang) เพราะข้อมูลกลุ่มนี้มีน้อยมาก (outlier) ทำให้โมเดลเรียนรู้ pattern ได้ไม่แม่นยำในโซนค่าสูง
3️⃣ TranSVM.ipynb — โมเดล Support Vector Machine
สถาปัตยกรรมโมเดล

ใช้ SVR (Support Vector Regression):

Kernel: RBF (Radial Basis Function) — เหมาะกับความสัมพันธ์แบบไม่เป็นเส้นตรง
C (regularization): 10.0 — ค่ายิ่งสูงยิ่งพยายามฟิตข้อมูล train ให้แม่นมากขึ้น (เสี่ยง overfit)
Epsilon: 0.1 — ขอบเขตที่ยอมให้คลาดเคลื่อนได้โดยไม่คิดเป็น error
Gamma: scale (auto-adjust ตามจำนวนฟีเจอร์และความแปรปรวนของข้อมูล)

ขั้นตอนเตรียมข้อมูลเหมือนกับ ANN ทุกประการ (ตัด leakage columns, scale, one-hot encode) เพื่อให้เปรียบเทียบได้อย่างยุติธรรม

ผลการประเมิน
ตัวชี้วัด	ค่า
MAE	1.8840
RMSE	4.5748
R²	0.8595 (85.95%)
การวิเคราะห์ตัวแปรสำคัญ (Permutation Importance)

ไฟล์นี้พิเศษตรงที่คำนวณ Permutation Importance ด้วยมือ (ไม่ใช้ sklearn.inspection) โดยสลับค่าคอลัมน์แต่ละตัวแบบสุ่ม แล้วดูว่า MAE แย่ลงแค่ไหน — ยิ่งแย่ลงมาก แปลว่าตัวแปรนั้นสำคัญมาก

Top 5 ตัวแปรที่มีผลต่อการทำนายมากที่สุด:

Blocked shots (การยิงที่ถูกบล็อก) — 0.4765
Wins (จำนวนนัดที่ชนะ) — 0.4503
Shots on target (ยิงเข้ากรอบ) — 0.4352
Offsides (ล้ำหน้า) — 0.4336
Shots (ยิงทั้งหมด) — 0.4316

→ สังเกตได้ว่าตัวแปรเกี่ยวกับ "การยิง" (Shots, Shots on target, Blocked shots, Offsides) ล้วนมีความสัมพันธ์สูงกับจำนวนประตู ซึ่งสมเหตุสมผลตามหลักฟุตบอล — ยิ่งยิงบ่อย ล้ำหน้าบ่อย (แสดงว่าเข้าใกล้ประตูบ่อย) ก็มีโอกาสทำประตูมากขึ้น

ตัวอย่างการทำนาย
กรณี Arsenal Forward (ยิงจริง 37) → SVM ทำนาย 41.38 ซึ่งคลาดเคลื่อนน้อยกว่า ANN มาก (ANN ทำนาย 66.46) → แสดงว่า SVM จัดการกับ outlier ได้ดีกว่า ในเคสนี้ แม้ภาพรวมจะแพ้ ANN
4️⃣ compare.ipynb — การเปรียบเทียบแบบยุติธรรม (Fair Comparison)

ไฟล์นี้รวมทั้งสองโมเดลมาเทรนบน ชุด Train/Test เดียวกันเป๊ะ (random_state=42 เดียวกัน) เพื่อขจัดความคลาดเคลื่อนจากการสุ่มแบ่งข้อมูลที่ต่างกัน ทำให้การเปรียบเทียบมีความน่าเชื่อถือ

ตารางเปรียบเทียบสรุป
โมเดล	MAE ↓	RMSE ↓	R² ↑
ANN ⭐	1.8126	4.1524	0.8842
SVM	1.8840	4.5748	0.8595

(↓ = ยิ่งน้อยยิ่งดี, ↑ = ยิ่งมากยิ่งดี)

เหตุผลการเลือกโมเดล ANN
RMSE ต่ำกว่า SVM อยู่ 0.4224 → ผิดพลาดรุนแรง (โดยเฉพาะกรณี outlier) น้อยกว่า
MAE ต่ำกว่า SVM อยู่ 0.0714 → ความคลาดเคลื่อนเฉลี่ยโดยรวมต่ำกว่าเล็กน้อย
R² สูงกว่า SVM อยู่ 0.0248 → อธิบายความแปรปรวนของข้อมูลได้ดีกว่า

สรุป: ANN ชนะทั้ง 3 ตัวชี้วัดบนชุดทดสอบเดียวกัน จึงถูกเลือกเป็นโมเดลที่ดีที่สุด

ข้อสังเกตเชิงลึกที่ควรพูดถึงตอนนำเสนอ (ประเด็นน่าสนใจ)
ANN ชนะในภาพรวม แต่ SVM แม่นกว่าในกรณี outlier (นักเตะดาวยิงที่ยิงประตูเยอะผิดปกติ) — เป็นจุดที่น่าอภิปรายว่าโมเดลไหนเหมาะกับ use case แบบไหน
ค่า R² ทั้งสองโมเดลอยู่ในช่วง 0.86-0.88 ถือว่า ค่อนข้างดี สำหรับข้อมูลกีฬาที่มีความไม่แน่นอนสูง
ความแตกต่างของ MAE ระหว่างสองโมเดล (0.07 ประตู) ค่อนข้างน้อยมาก เมื่อเทียบกับ RMSE ที่ต่างกันชัดเจนกว่า (0.42) → บ่งชี้ว่าความแตกต่างหลักอยู่ที่การจัดการค่าผิดปกติ (outliers) มากกว่าความแม่นยำเฉลี่ยทั่วไป
